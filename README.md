# Google Snake Game

A classic Snake game implementation with modern styling, inspired by Google's version.

## Features

- Smooth gameplay with responsive controls
- Score tracking with local high score persistence
- Progressive difficulty (speed increases as you score)
- Beautiful gradient UI design
- Animated snake with directional eyes
- Game over screen with restart functionality

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game" to begin
3. Use arrow keys to control the snake:
   - ← Left Arrow: Move left
   - → Right Arrow: Move right
   - ↑ Up Arrow: Move up
   - ↓ Down Arrow: Move down
4. Eat the red food to grow and increase your score
5. Avoid hitting the walls or yourself
6. Try to beat your high score!

## Game Rules

- Each food eaten awards 10 points
- The snake grows longer with each food consumed
- Game speed increases every 50 points
- The game ends when the snake hits a wall or itself
- High scores are saved in browser local storage

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `script.js` - Game logic and mechanics

## Technologies Used

- HTML5 Canvas
- CSS3 (Gradients, Flexbox, Animations)
- Vanilla JavaScript (ES6+)
